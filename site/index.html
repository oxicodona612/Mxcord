Install

Mxcord is a Revenge plugin on Android and a Vencord plugin on desktop. Both work the same way and can be used at the same time.

You need Discord for Android with Revenge or another Vendetta-compatible mod.

  1. In Discord, open Settings › Revenge › Plugins and tap +.
  2. Paste this URL and confirm the warning:
    https://oxicodona612.github.io/Mxcord/
  3. Open the Mxcord settings and log in.

Revenge checks for updates each time Discord starts, so new versions arrive on their own.

Vencord only loads third-party plugins in builds made from source, so Mxcord is built together with Vencord. You need Git, Node.js 18 or later and pnpm. Run these in a terminal:

git clone https://github.com/Vendicated/Vencord
git clone https://github.com/oxicodona612/Mxcord
node Mxcord/tools/install-vencord.mjs Vencord
cd Vencord
pnpm install --frozen-lockfile
pnpm build
pnpm inject
  1. pnpm inject asks which Discord to patch. Pick the one you use (Stable, PTB or Canary).
  2. Restart Discord and enable Mxcord under Settings › Vencord › Plugins.
  3. Restart Discord once more so the Matrix badges appear, then open the plugin's settings and log in.

Setup guides

Step-by-step help for logging in, encryption and everyday use.

Logging in
  1. Open the Mxcord settings: on Android under Settings › Revenge › Plugins, on desktop under Settings › Vencord › Plugins (the cog next to Mxcord).
  2. Enter the homeserver URL. For encrypted chats this must be your pantalaimon address, for example https://pan.example.com. Without encryption, use your homeserver's address.
  3. Enter your username, either the full Matrix ID (@you:example.com) or just the name (you), and your password.
  4. Tap Log in. Your Matrix DMs appear in the DM list within a few seconds.

Your password is only sent to your homeserver to log in. Mxcord keeps the access token on your device.

Encrypted chats with pantalaimon

Mxcord doesn't encrypt or decrypt anything itself. pantalaimon is a small proxy that runs next to your homeserver and does the encryption for clients that connect through it.

  1. Install pantalaimon on the server or another always-on machine, following the pantalaimon guide. It listens on port 8009 by default.
  2. Give it its own address. With a Cloudflare Tunnel, add a public hostname such as pan.example.com pointing at http://localhost:8009. With Caddy or nginx, proxy a subdomain to port 8009. A LAN address like http://192.168.1.2:8009 works too, but only at home.
  3. Log in to Mxcord with that address. Keep your homeserver's own address for Element and other apps; only Mxcord should go through pantalaimon.
  4. Optionally, verify the pantalaimon device so Element stops warning about it.
Verifying the pantalaimon device

pantalaimon can't do cross-signing, so Element shows its device as unverified and marks messages you send from Discord with a warning. The verification script signs the device with your cross-signing key instead.

node Mxcord/tools/verify-device.mjs https://example.com

It asks for your password and your recovery key (48 characters starting with Es) or security phrase, the ones Element gave you when you set up recovery. Pick the pantalaimon device from the list. Lost the key? Element can make a new one under Settings › Encryption › Recovery.

The Discord (Mxcord) session has no encryption keys of its own and always shows as unverified. That's expected.

Starting chats and message requests

Add by Matrix starts a new DM. On Android it replaces "Find Your Friends" on the Add Friends screen; on desktop it is in the Vencord toolbox; on both it is in the Mxcord settings. Type a full Matrix ID, or just a name for someone on your own server.

When someone invites you on Matrix, the chat appears under Message Requests. Accept it to join and read their messages, or ignore it to decline.

Updating

Android: nothing to do. Revenge downloads new versions when Discord starts.

Desktop: run git pull in both the Mxcord and Vencord folders, then run the install script and pnpm build again and restart Discord. If a Discord update removed Vencord, run pnpm inject again.

Features

Matrix chats behave like any other Discord DM.

Native DMs

Matrix conversations sit in the DM list next to your Discord chats, sorted by activity, with a Matrix badge.

Full messaging

Send, reply, edit and delete. Older history loads as you scroll.

End-to-end encryption

Encrypted rooms work through pantalaimon running next to your homeserver.

Profiles

Avatars and display names come from Matrix and stay up to date. Profiles show the Matrix ID.

Message requests

DM invites appear under Message Requests and can be accepted or ignored.

Notifications

New messages notify like any other DM, on Android and desktop.

Private by design

Mxcord only talks to your homeserver. Discord never sees your Matrix messages, and requests about Matrix chats are answered on your device.

No duplicates

Rooms bridged from Discord by mautrix-discord are skipped, so your Discord DMs aren't shown twice.

FAQ

Common errors and how to fix them. The full FAQ has more.

"User ID is malformed"

The username was half a Matrix ID, like you:example.com without the @, or @you without the server. Enter @you:example.com or just you. Current versions fix this automatically.

"Network request failed" or "fetch failed"

Discord couldn't reach the URL. Check that <url>/_matrix/client/versions opens in a browser on the same device. On Android, use https://, since stock Discord blocks plain http://. LAN addresses only work on the same network.

Messages say "Unable to decrypt message", or my replies aren't encrypted

Mxcord is connected to the homeserver directly instead of through pantalaimon. Log out, change the URL to your pantalaimon address and log in again. If only old messages fail, they were sent before pantalaimon existed; import your keys as described in the pantalaimon guide.

Element warns "sent by a device unverified by the owner"

Messages from Discord are encrypted by pantalaimon's device, which isn't cross-signed yet. Verify it and the warning disappears from new and old messages.

"Session expired. Log in again."

The session was signed out, usually from Element's session list. Log in again from the Mxcord settings.

A Matrix chat doesn't show up

Only one-to-one DMs are shown; group rooms and spaces aren't. Chats with mautrix-discord puppets (@discord_…) are skipped on purpose.

Mxcord isn't in Vencord's plugin list

The official Vencord installer can't load third-party plugins. Use the desktop install steps, and make sure pnpm inject patched the Discord you actually open.

A new version doesn't show up

On Android, fully close Discord and open it again. On desktop, follow the update steps.

Known issues

Things that don't work yet, or work a little differently than in Element.

  • Only one-to-one DMs are supported. Group rooms, spaces, calls, reactions and threads aren't.
  • Images and files show as a text line with their name instead of a preview.
  • Notifications only arrive while Discord is running, in the foreground or background.
  • Matrix DMs can vanish for a few seconds when Discord reconnects. They come back on their own.
  • When you accept an invite from another server, the earlier messages can take up to a minute to appear.
  • Profiles of Matrix users show a "Member since" date of December 2014. It is a placeholder, not their real join date.
  • On Android, "Add by Matrix" relies on Discord's English "Find Your Friends" label. In other languages, use the button in the Mxcord settings.
  • On desktop, Discord updates can remove Vencord. Run pnpm inject again.
  • Client modifications are against Discord's Terms of Service. Use them at your own risk.
